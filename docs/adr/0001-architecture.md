# ADR 0001：纯前端 PWA 与唯一网格真相源

- 状态：已接受
- 日期：2026-08-29

## 背景

产品需要在保护本地图片隐私的前提下完成颜色匹配、编辑、统计、恢复和多格式导出，且数据一致性比云端能力优先。

## 决定

采用 React + TypeScript + Vite 的纯前端 PWA；转换在 Web Worker 中执行；项目存 IndexedDB；所有统计和导出只读同一个 `PatternGrid`。色卡按注册表加载，算法不硬编码品牌。

## 后果

应用可静态部署并离线运行，不需要账号或服务器。大型图像受浏览器内存限制；PDF 字体、跨设备同步与服务端 AI 留给独立后续决策。
