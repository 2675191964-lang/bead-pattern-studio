# 已知限制

- 内置色卡不是实体批次测量结果；屏幕颜色不可替代实物打样。
- 浏览器解码支持常见 EXIF 方向，但 HEIC/AVIF 不在首版输入范围。
- PDF 使用标准拉丁字体，施工信息以色号和英文标签输出；中文项目名会安全替换为 ASCII 标题，避免缺字方块。PNG/SVG/CSV/JSON 保留中文。
- 超过 200×200 的网格被拒绝；大导出会先给出像素与内存估算。
- Safari/Firefox 属尽量支持范围，正式门禁以当前 Chrome/Edge 为准。
- 任务书提到的同目录《开源与市场调研报告》未随本次附件提供，因此候选仓库核验基于任务书列出的仓库和当前 GitHub 主仓库状态。
