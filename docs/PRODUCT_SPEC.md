# 产品规格基线

## 目标

用户上传图片后，在本地生成由可追溯色号组成的拼豆网格；网格可编辑，所有视图、统计、保存与导出必须由同一个 `PatternGrid` 派生。

## 首版范围（M0-M3）

- JPG/PNG/WebP 拖拽、选择、粘贴与移动端拍照入口。
- EXIF 方向由浏览器解码处理；支持裁剪、缩放、网格与底板设置。
- sRGB/D65、Lab、CIEDE2000、确定性限色、无抖动/Floyd-Steinberg/Bayer。
- 平面、施工、圆豆与底板分区视图。
- 画笔、橡皮、填充、吸色、矩形区域、撤销/重做、换色与禁用重映射。
- 实时色号数量、占比、总豆数、物理尺寸与底板数。
- IndexedDB 自动保存/恢复；PNG、SVG、PDF、CSV、项目 JSON 导出。
- 桌面三栏与 360px 手机画布优先布局；PWA 离线应用壳。

## 明确不做

账号、云同步、社区、支付、商城、版权图库、蓝牙设备、远端图片分析与第三方 AI。品牌名称仅用于兼容性描述，不代表合作、授权或官方认证。

## 数据不变量

`总豆数 = 各色数量之和 = PatternGrid 中非透明格数`。项目恢复、CSV、PDF 与画面统计都必须一致。
