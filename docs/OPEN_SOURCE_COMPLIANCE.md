# 开源合规

## 实现策略

本仓库代码为独立实现。`hanyanshuo/pindou-studio`（MIT）与 `reason7871/perler-beads-ai`（Apache-2.0）仅用于可行性和功能边界调研，没有复制其代码或素材。

色卡记录来自 `maxcleme/beadcolors` 的 MIT 许可 CSV，固定于提交 `f97ff4283d03cef5cd7e1071a86f5892e0c0c61b`。保留许可证全文与来源说明。

## 禁止复用

- 未知许可证代码、品牌 Logo、包装图片、官方色卡图片、用户作品与第三方模板。
- 候选仓库中的 API 密钥、代理、追踪、AI 上传或商业跳转。
- 任何暗示品牌官方认证、授权合作或实体颜色绝对准确的文案。
